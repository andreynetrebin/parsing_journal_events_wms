📚 Справочник API дашборда ТСД

Основные эндпоинты для программного получения данных. Нажмите на заголовок, чтобы увидеть пример HTTP-запроса и формат ответа.

1. Поиск медленных запросов (/api/dashboard/slow-requests)

Возвращает список успешных пар, время обработки которых превысило порог.

HTTP GET Запрос:
GET /api/dashboard/slow-requests?threshold_ms=5000&start_date=2026-11-02&end_date=2026-11-04&limit=10
2. Детали события: тела запроса и ответа (/api/events/{request_id})

Получение полных данных (включая JSON-тела) по конкретному request_id.

HTTP GET Запрос:
GET /api/events/1793685601570
3. Топ медленных методов в разрезе ТСД (/api/dashboard/slow-methods)

Агрегированная статистика: какие методы на каких устройствах потребляют больше всего суммарного времени.

HTTP GET Запрос:
GET /api/dashboard/slow-methods?limit=10
4. 📥 Потоковый экспорт данных с телами запросов/ответов (/api/export)

Позволяет выгружать данные из витрины (tsd_pairs_mart) напрямую в файл. Всегда включает поля request_body_json и response_body_json. Поддерживает потоковую передачу, что позволяет безопасно выгружать сотни тысяч записей.

Доступные параметры запроса:
ПараметрТипОписаниеПример
formatstrcsv (по умолч.), jsonl, jsonformat=jsonl
start_datestrНачало периода2026-11-15 00:00:00
end_datestrКонец периода2026-11-16 23:59:59
methodlistФильтр по методу (можно несколько)method=A&method=B
devicelistФильтр по ТСД (можно несколько)device=78:B8:D6:..
actionlistФильтр по действию (можно несколько)action=PickingSKU
pair_statusstrok, no_response, no_requestpair_status=no_response
min_msintМинимальное время обработки (мс)min_ms=5000
limitintМакс. записей (по умолч. 10000, макс 500000)limit=50000
Пример 1: Выгрузка медленных запросов в CSV (для Excel)
curl -o slow_requests.csv "http://192.168.100.174/api/export?format=csv&method=GetGeneralDatas&min_ms=5000&start_date=2026-11-15%2000:00:00&end_date=2026-11-16%2023:59:59&limit=50000"
Пример 2: Выгрузка всех запросов без ответа в JSONL (для скриптов)
curl -o orphans.jsonl "http://192.168.100.174/api/export?format=jsonl&pair_status=no_response&limit=100000"
Пример 3: Python скрипт для потокового скачивания
import requests

params = {
    "format": "jsonl",
    "method": ["GetGeneralDatas", "InventorySKU"],
    "min_ms": 5000,
    "start_date": "2026-11-15 00:00:00",
    "limit": 50000
}

# stream=True критически важен для больших файлов, чтобы не забить RAM
with requests.get("http://192.168.100.174/api/export", params=params, stream=True) as r:
    r.raise_for_status()
    with open("export.jsonl", "wb") as f:
        for chunk in r.iter_content(chunk_size=8192):
            f.write(chunk)

print("✅ Выгрузка завершена!")

📥 Выгрузка данных из витрины

Экспортируются данные из таблицы tsd_pairs_mart с учётом текущих фильтров. Включает тела запроса и ответа.

🔍 Активные фильтры:
Не выбраны
Найдено по текущим фильтрам: — строк. Большие объёмы могут долго скачиваться. CSV и JSONL работают потоково.
Файл будет содержать поля request_body_json и response_body_json с полными телами запроса и ответа.
